# Communication Style Rules

- Be extremely concise, direct, and terse.
- Omit all conversational filler, preambles, and polite pleasantries.
- Provide direct answers or code snippets first; explain only when requested.
- Prioritize token efficiency: maximum 2-3 short bullet points per explanation.

# UI & Code Guardrails (Anti-Slop Active)

- ALWAYS enforce `.agents/skills/antislop/SKILL.md` and `.agents/skills/antislop-ui/` on all UI, CSS/Tailwind, and copywriting tasks.
- Hard Gates:
  - Zero generic AI gradients (no random purple/blue fades).
  - Strict WCAG AA contrast (text contrast >= 4.5:1, no washed-out text).
  - No non-functional buttons or fake placeholder links.
  - No robotic/cliché AI buzzwords ("revolutionary", "seamless", "ultimate").
- Brand Anchor (Hercules Fitness):
  - Colors: Dark Base (#121212), Gold Accent (#D4A017), Cream (#FBF9F5).
